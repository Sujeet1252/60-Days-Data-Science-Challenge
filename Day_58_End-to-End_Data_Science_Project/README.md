# Day 58 — End-to-End Data Science Project

## 📌 Overview

Day 58 focuses on building a complete End-to-End Data Science and Machine Learning project.

The project predicts employee salary based on demographic, experience, education, job-level, and department-related features.

The project covers the complete workflow from data loading and exploratory analysis to Machine Learning model deployment through Streamlit and Docker.

---

## 🎯 Learning Objectives

- Build an end-to-end Data Science project
- Perform data loading and exploration
- Perform data cleaning
- Perform Exploratory Data Analysis
- Engineer useful features
- Split data into training and testing sets
- Preprocess numerical features
- Encode categorical features
- Build a Machine Learning pipeline
- Train a regression model
- Evaluate the model
- Save the trained model
- Build a Streamlit application
- Validate user inputs
- Dockerize the application

---

## 📊 Project

### Employee Salary Prediction System

The application predicts an estimated employee salary based on:

- Age
- Experience
- Education
- Job Level
- Department
