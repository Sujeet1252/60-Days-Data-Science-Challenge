# Day 49 - Database-Driven Student Management REST API

## Overview
SQLite is used as a persistent database to store student records.

## Technologies Used

- Python
- Flask
- SQLite
- REST API
- JSON
- Postman
- Git
- GitHub

## Features

- Create student
- Read all students
- Read a single student
- Update student
- Delete student
- Input validation
- HTTP status codes
- SQLite database
- Search students by name
