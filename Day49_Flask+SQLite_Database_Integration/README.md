# Day 49 - Flask + SQLite Database Integration

## 📌 Overview

Day 49 focuses on integrating a SQLite database with Flask REST APIs.

The main goal is to replace temporary Python data structures with a persistent database.

---

## 🎯 Learning Objectives

- Understand SQLite
- Create SQLite databases
- Create database tables
- Insert data
- Read data
- Update data
- Delete data
- Connect Flask with SQLite
- Build database-driven REST APIs
- Use parameterized SQL queries
- Validate API input
- Test APIs using Postman
- Understand persistent data storage
