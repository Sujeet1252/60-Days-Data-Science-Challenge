Multi-User Student Management REST API

## 📌 Overview

A Flask-based Student Management REST API with user authentication, SQLite database integration, protected endpoints, and user-specific data access.

The project combines Flask, REST APIs, SQLite, authentication, sessions, and CRUD operations into a single application.

---

## 🎯 Features

- User registration
- Secure password hashing
- User login
- Session-based authentication
- Logout
- Protected REST API
- Create students
- Read students
- Update students
- Delete students
- SQLite database
- User-specific student records
- Input validation
- HTTP status codes
- Postman API testing
