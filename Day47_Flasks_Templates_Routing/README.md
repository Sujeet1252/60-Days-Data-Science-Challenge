# 🎓 Day 47 - Student Management Web Interface

A simple **Student Management Web Interface** built using **Python, Flask, HTML, and Jinja2**.

This project is part of my **60 Days Data Science Challenge** and focuses on learning Flask fundamentals, routing, templates, URL parameters, and Jinja2 template logic.

---

## 📌 Project Overview

The application provides a simple web interface to manage and display student information.

It contains:

- 🏠 Home page
- ℹ️ About page
- 🎓 Student list
- 👤 Individual student details
- ✅ Pass/Fail status based on marks
- 🔗 Navigation between multiple pages
- 🧩 Jinja2 template inheritance and conditional logic

---

## 🎯 Objectives

The main objectives of this project are to learn:

- Flask application structure
- Flask routes
- `render_template()`
- HTML templates
- Jinja2 syntax
- Template inheritance
- `for` loops in Jinja2
- `if/else` conditions
- Dynamic URL parameters
- Passing Python data to HTML
- Building a multi-page Flask application
