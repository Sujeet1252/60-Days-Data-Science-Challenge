# Day 48 - REST API Development with Flask

## 📌 Overview

Day 48 focuses on building REST APIs using Flask.

The goal is to understand how frontend applications, backend servers, databases, and machine learning models communicate through APIs.

---

## 🎯 Learning Objectives

- Understand APIs
- Understand REST architecture
- Learn HTTP methods
- Learn GET requests
- Learn POST requests
- Learn PUT requests
- Learn DELETE requests
- Understand JSON
- Learn CRUD operations
- Understand HTTP status codes
- Build Flask REST APIs
- Validate API input
- Test APIs using Postman / Thunder Client

---

## 📚 Topics Covered

### 1. API

API stands for Application Programming Interface.

It allows different software applications to communicate with each other.

### 2. REST API

REST is an architectural style used for designing web APIs.

### 3. HTTP Methods

- GET - Read data
- POST - Create data
- PUT - Update data
- DELETE - Delete data

### 4. JSON

JSON is commonly used to exchange data between clients and APIs.

Example:

```json
{
    "id": 1,
    "name": "Rahul",
    "marks": 85
}
