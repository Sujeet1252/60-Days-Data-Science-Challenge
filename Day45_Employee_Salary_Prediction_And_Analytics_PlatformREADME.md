# Employee Salary Prediction & Analytics Platform

## 📌 Overview

A machine learning project designed to predict employee
salary based on demographic, professional, and employment
features.

## 🎯 Objective

Build an end-to-end regression system that can:

- Analyze salary patterns
- Predict employee salary
- Compare multiple ML models
- Optimize model performance
- Provide business insights

## 🔄 Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Engineering
5. Preprocessing Pipeline
6. Model Training
7. Cross Validation
8. Hyperparameter Tuning
9. Model Evaluation
10. Model Saving
11. Prediction

## 🤖 Models

- Linear Regression
- Random Forest Regressor
- Tuned Random Forest

## 📊 Evaluation Metrics

- MAE
- RMSE
- R² Score
